# Basic Admin Plugins for RankGun
>  RankGun is a, popular, secure Roblox group management and automation tool designed to handle rank-ups, staff management, and member activity tracking without needing to set up complex, manual bot infrastructure.
## How to setup
* First, please download the files. 
* Once you download the files, open your Roblox Studio, and navigate to the experience you want to add the plugins to.
* Now, click **File** at the top of the screen.
* Click 'Import Roblox Model'
