# 🧩 Basic Admin Plugins for RankGun

> **RankGun** is a secure and easy-to-use Roblox group management and automation system.  
> It helps you manage rank-ups, staff permissions, and member activity without needing complicated bots or external infrastructure.

---

# 📦 What These Plugins Do

These plugins extend your **Basic Admin** by connecting it to RankGun, allowing you to:

- Promote users to the next rank
- Demote users to a selected rank
- Set a user to your desired rank (!! COMING SOON !! )

# ⚙️ Installation Guide

Follow these steps carefully to ensure everything works correctly.

## 1. Download the Files
Start by downloading all provided plugin files.  
Make sure you keep them in an easy-to-find location on your computer.

---

## 2. Open Roblox Studio
Launch **Roblox Studio** and open the experience (game) where you want to install RankGun plugins.

---

## 3. Import the Plugins
Once inside your place:

1. Click **File** in the top-left corner of Roblox Studio  
2. Select **Import Roblox Model**  
3. Locate and import **both plugin script files**

---

## 4. Locate Basic Admin
In your Explorer panel:

- Find your **Basic Admin system**
- Open the **Plugins** folder inside it

---

## 5. Add the Modules
Drag and drop both imported **ModuleScripts** into the **Plugins** folder.

Your structure should look similar to this:

Basic-Admin-Essentials
└── Plugins
    ├── PromotePlugin
    └── DemotePlugin
